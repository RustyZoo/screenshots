# Platforms

The latest green master build of RustyZoo on the GitHub runner of each system, on its real video
driver (software renderer, windowed). Per system, `shot` is the window's own read-back and
`desktop` is a screenshot of the desktop with the window open. A desktop capture that comes out
black is not kept.
